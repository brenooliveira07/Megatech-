# Megatech Smart Stock

Crie uma aplicação web moderna chamada "Megatech - Controle Inteligente de Produtos".

Contexto:

A Megatech é uma loja de tecnologia especializada na venda de acessórios eletrônicos como fones de ouvido, capinhas, películas, carregadores e cabos. Atualmente o controle é feito manualmente e o objetivo é digitalizar o processo de vendas e estoque.

Objetivo do sistema:

Permitir o gerenciamento completo de produtos, vendas e estoque em tempo real.

Design:

- Interface moderna e profissional.

- Paleta de cores: azul escuro, preto, branco e detalhes em azul claro.

- Layout responsivo para computador, tablet e celular.

- Dashboard semelhante a sistemas empresariais modernos.

- Ícones intuitivos e visual limpo.

Funcionalidades:

1. Login

- Tela de login para administrador.

- Campos de usuário e senha.

- Botão entrar.

2. Dashboard

- Total de produtos cadastrados.

- Produtos com estoque baixo.

- Produtos esgotados.

- Total de vendas do dia.

- Gráficos de movimentação de estoque.

- Resumo geral do sistema.

3. Cadastro de Produtos

- Nome do produto.

- Categoria.

- Preço de venda.

- Quantidade em estoque.

- Descrição.

- Código do produto.

- Data de cadastro.

- Botões editar e excluir.

4. Controle de Estoque

- Listagem completa dos produtos.

- Pesquisa por nome.

- Filtro por categoria.

- Quantidade disponível.

- Status:

  - Em estoque

  - Estoque baixo

  - Esgotado

5. Registro de Vendas

- Selecionar produto.

- Informar quantidade vendida.

- Calcular valor total automaticamente.

- Registrar venda.

- Dar baixa automática no estoque.

6. Alertas

- Exibir alerta visual quando o estoque estiver abaixo do mínimo.

- Exibir alerta de produto esgotado.

- Destacar produtos críticos em vermelho.

7. Relatórios

- Produtos mais vendidos.

- Histórico de vendas.

- Relatório de estoque.

- Quantidade vendida por período.

8. Usuários

- Perfil Administrador.

- Perfil Funcionário.

Banco de dados:

Criar estrutura para armazenar:

- Produtos

- Categorias

- Vendas

- Usuários

- Histórico de movimentações

Requisitos do projeto:

- Cadastro de produtos.

- Registro de vendas.

- Baixa automática de estoque.

- Visualização da quantidade atual.

- Alerta de estoque baixo.

- Interface simples e intuitiva.

- Tempo de resposta rápido.

- Sistema preparado para expansão futura.

Nome do sistema:

Megatech - Controle Inteligente de Produtos

Crie todas as páginas, componentes, tabelas, formulários, dashboard, navegação lateral e experiência completa de um sistema profissional de gestão de estoque.
